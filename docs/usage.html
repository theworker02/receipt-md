receipt-md

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

receipt-md [options] <title> <pass|fail> [file]
Tip: receipt-md --help prints this text in the terminal. receipt-md --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
<title>Heading written as # title.
<pass|fail>pass/ok/true/1 → PASS; fail/false/0 → FAIL.
[file]Output path. Default: ./RECEIPT.md

Exit codes

CodeMeaning
0Receipt written and result is PASS.
1Bad usage, or receipt written as FAIL.

Configuration

No configuration file. The process exit code matches the receipt: 0 for PASS, 1 for FAIL (after the file is written).

Worked examples

Success path

receipt-md "nightly" pass
# nightly

- timestamp: 2026-08-23T16:00:00.000Z
- result: PASS

Failure path

receipt-md "nightly" fail ; echo exit:$?

The file is still written with result FAIL. Exit code is 1.
