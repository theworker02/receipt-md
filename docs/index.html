receipt-md

Generate durable PASS/FAIL markdown receipts with optional JSON sidecars.

JSR @theworker02/receipt-md ESM MIT Node.js CLI ≥ 18

Overview

receipt-md turns build, grading, and CI outcomes into small durable artifacts that are easy to inspect and archive.

Public distribution now lives on @theworker02/receipt-md on JSR.

Package API

import { render } from "jsr:@theworker02/receipt-md";

console.log(render({
  title: "CI",
  pass: true,
  notes: ["tests passed"]
}));

CLI

git clone https://github.com/theworker02/receipt-md.git
cd receipt-md
node src/cli.js "CI" pass
