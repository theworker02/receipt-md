receipt-md

Write a markdown receipt with a title, ISO timestamp, and PASS or FAIL from argv.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

CI logs disappear. A RECEIPT.md in the workspace is a durable, human-readable proof of the last run.

Workshop graders, local CI wrappers, and anyone attaching a result file to an artifact folder.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/receipt-md.git
receipt-md --help
node src/cli.js --help

Usage

Synopsis: receipt-md [options] <title> <pass|fail> [file]

See the full CLI reference for every flag, exit code, and example.

receipt-md 1.00 (1.0.0)

Usage:
  receipt-md <title> <pass|fail> [file]
  receipt-md --help
  receipt-md --version

Writes markdown:
  # <title>
  - timestamp: <ISO>
  - result: PASS|FAIL

Default file: ./RECEIPT.md
Exit 0 on PASS, 1 on FAIL (file is still written).

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples:
  receipt-md "CI" pass
  receipt-md "e2e" fail ./artifacts/RECEIPT.md

Examples

Success

receipt-md "nightly" pass
# nightly

- timestamp: 2026-08-23T16:00:00.000Z
- result: PASS

Failure

receipt-md "nightly" fail ; echo exit:$?

The file is still written with result FAIL. Exit code is 1.

Missing title:

receipt-md
