Write RECEIPT.md with a title, ISO timestamp, and pass/fail taken from argv.

## Install

```bash
git clone https://github.com/theworker02/receipt-md.git
cd receipt-md
npm install -g .
```

Package version: **1.00** (`1.0.0`).

## Usage

```bash
receipt-md CI pass
```
